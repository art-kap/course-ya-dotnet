# course-ya-dotnet
Проектные работы курса .NET

## Практическая работа №1
В данной работе реализован базовый REST API для создания, просмотра, обновления и удаления мероприятий.

## Запуск проекта
Находясь в корневой директории, выполните команду
```bash
dotnet run --project CourseWebApiProject/CourseWebApiProject
```

## Swagger
JSON-документация доступна по адресу http://localhost:5109/swagger/v1/swagger.json

Swagger UI запускается по адресу http://localhost:5109/swagger/index.html

## Методы API контроллера Events
### GET /events
Получить список всех событий
| Код состояния | Описание  |
|---------------|-----------|
| 200           | OK        |

### GET /events/{id}
Получить событие по id
| Код состояния | Описание           |
|---------------|--------------------|
| 200           | OK                 |
| 404           | Событие не найдено |

### POST /events
Создать событие
| Код состояния | Описание           |
|---------------|--------------------|
| 201           | Успешное создание  |
| 400           | Данные некорректны |

### PUT /events/{id}
Обновить событие целиком
| Код состояния | Описание            |
|---------------|---------------------|
| 204           | Успешное обновление |
| 400           | Данные некорректны  |
| 404           | Событие не найдено  |

### DELETE /events/{id}
Удалить событие
| Код состояния | Описание           |
|---------------|--------------------|
| 200           | OK                 |
| 404           | Событие не найдено |

## Данные для запроса/ответа
### EventResponseDto
Полная информация о событии
| Поле        | Назначение      | Тип      |
|-------------|-----------------|----------|
| id          | Идентификатор   | Guid      |
| title       | Название        | string   |
| description | Описание        | string   |
| startAt     | Время начала    | DateTime |
| endAt       | Время окончания | DateTime |

### EventRequestDto
Информация для добавления или обновления события
| Поле        | Назначение      | Тип      | Обязательное поле |
|-------------|-----------------|----------|-------------------|
| title       | Название        | string   | Да                |
| description | Описание        | string   | Нет               |
| startAt     | Время начала    | DateTime | Да                |
| endAt       | Время окончания | DateTime | Да                |
