# course-ya-dotnet
Проектные работы курса .NET

## Практическая работа №3
В данной работе реализованы:
* базовый REST API для создания, просмотра, обновления и удаления мероприятий;
* базовый REST API для создания и просмотра бронирований на мероприятия;
* фоновый сервис для асинхронной обработки поступивших бронирований.

## Запуск и тестирование проекта
Перед запуском нужно перейти из корневой папки в папку солюшена
```bash
cd CourseWebApiProject
```

### Сборка проекта
```bash
dotnet build
```

### Запуск тестов
```bash
dotnet test
```

### Запуск проекта
```bash
dotnet run --project CourseWebApiProject
```

## Swagger

## Методы API контроллера Events
### GET /events
Получить список событий, удовлетворяющих фильтру, в формате [PaginatedResult](#paginatedresult)
| Код состояния | Описание  |
|---------------|-----------|
| ```200```     | ```OK```  |

Параметры фильтра (необязательны):
| Поле           | Назначение                 | Тип             | Значение по умолчанию |
|----------------|----------------------------|-----------------|-----------------------|
| ```title```    | Название                   | ```string?```   | ```null```            |
| ```from```     | Время начала               | ```DateTime?``` | ```null```            |
| ```to```       | Время окончания            | ```DateTime?``` | ```null```            |
| ```page```     | Номер страницы             | ```int```       | ```1```               |
| ```pageSize``` | Кол-во событий на странице | ```int```       | ```10```              |

### GET /events/{id}
Получить событие по ```id```
| Код состояния | Описание           |
|---------------|--------------------|
| ```200```     | OK                 |
| ```404```     | Событие не найдено |

### POST /events
Создать событие
| Код состояния | Описание           |
|---------------|--------------------|
| ```201```     | Успешное создание  |
| ```400```     | Данные некорректны |

### PUT /events/{id}
Обновить событие целиком
| Код состояния | Описание            |
|---------------|---------------------|
| ```204```     | Успешное обновление |
| ```400```     | Данные некорректны  |
| ```404```     | Событие не найдено  |

### DELETE /events/{id}
Удалить событие
| Код состояния | Описание           |
|---------------|--------------------|
| ```204```     | Успешное удаление  |
| ```404```     | Событие не найдено |

### POST /events/{id}/book
Создать бронь по id события
| Код состояния | Описание                               |
|---------------|----------------------------------------|
| ```202```     | Успешное создание, ожидается обработка |
| ```404```     | Событие не найдено                     |

## Данные для запроса/ответа
### EventResponseDto
Полная информация о событии
| Поле              | Назначение      | Тип            |
|-------------------|-----------------|----------------|
| ```id```          | Идентификатор   | ```Guid```     |
| ```title```       | Название        | ```string```   |
| ```description``` | Описание        | ```string```   |
| ```startAt```     | Время начала    | ```DateTime``` |
| ```endAt```       | Время окончания | ```DateTime``` |

### EventRequestDto
Информация для добавления или обновления события
| Поле              | Назначение      | Тип            | Обязательное поле |
|-------------------|-----------------|----------------|-------------------|
| ```title```       | Название        | ```string```   | Да                |
| ```description``` | Описание        | ```string```   | Нет               |
| ```startAt```     | Время начала    | ```DateTime``` | Да                |
| ```endAt```       | Время окончания | ```DateTime``` | Да                |

### PaginatedResult
Результат пагинации
| Поле                    | Назначение                           | Тип                      |
|-------------------------|--------------------------------------|--------------------------|
| ```eventsCount```       | Общее количество событий             | ```int```                |
| ```currentPageEvents``` | События на текущей странице          | ```EventResponseDto[]``` |
| ```currentPageNumber``` | Номер текущей страницы               | ```int```                |
| ```currentPageSize```   | Кол-во элементов на текущей странице | ```int```                |

### BookingInfo
Полная информация о брони
| Поле          | Назначение            | Тип                                                                                      |
|---------------|-----------------------|------------------------------------------------------------------------------------------|
| ```id```      | Идентификатор брони   | ```Guid```                                                                               |
| ```eventId``` | Идентификатор события | ```Guid```                                                                               |
| ```status```  | Описание              | ```int``` (```0``` - ```Pending```, ```1``` - ```Confirmed```, ```2``` - ```Rejected```) |

### ProblemDetails
Информация об ошибке
| Поле           | Назначение                                                           | Тип          |
|----------------|----------------------------------------------------------------------|--------------|
| ```type```     | Ссылка (URI), определяющая класс или тип ошибки                      | ```string``` |
| ```title```    | Короткое описание ошибки, одинаковое для всех случаев                | ```string``` |
| ```status```   | Код состояния HTTP                                                   | ```int```    |
| ```detail```   | Подробное описание конкретного случая ошибки                         | ```string``` |
| ```instance``` | Ссылка (URI), указывающая на конкретное место возникновения проблемы | ```string``` |

## Примеры использования методов API контроллера Events
### Создание события
Пример события с корректными данными:
```
{
  "title": "test event",
  "description": "",
  "startAt": "2026-08-12T00:00:00",
  "endAt": "2026-08-13T00:00:00"
}
```
Ожидаемый результат - ```201 Created``` (```id``` задается произвольно)
```
{
  "id": "34211b2c-f70b-4c2d-9135-b457ca31a95e",
  "title": "test event",
  "description": "",
  "startAt": "2026-08-12T00:00:00",
  "endAt": "2026-08-13T00:00:00"
}
```
Пример события с некорректными данными (дата окончания раньше даты начала):
```
{
  "title": "test event",
  "description": "",
  "startAt": "2026-08-12T00:00:00",
  "endAt": "2026-08-11T00:00:00"
}
```
Ожидаемый результат - ошибка ```400```
```
{
  "title": "Недопустимые данные.",
  "status": 400,
  "detail": "Точное время окончания должно быть позже времени начала."
}
```
### Получение события по id
Пример запроса для получения события по ```id```:

http://localhost:5109/events/34211b2c-f70b-4c2d-9135-b457ca31a95e

Ожидаемый результат для события с существующим ```id```:
```
{
  "id": "34211b2c-f70b-4c2d-9135-b457ca31a95e",
  "title": "test event",
  "description": "",
  "startAt": "2026-08-12T00:00:00",
  "endAt": "2026-08-13T00:00:00"
}
```
Если ```id``` не существует, то ожидается ошибка ```404```:
```
{
  "title": "Ресурс не найден.",
  "status": 404,
  "detail": "Событие с id=34211b2c-f70b-4c2d-9135-b457ca31a95e не найдено."
}
```
### Получение событий по фильтру
Пример запроса с получением событий по фильтру:

http://localhost:5109/events?title=TEST&from=2026-08-01&to=2026-08-31
* в названии есть ```TEST``` вне зависимости от регистра
* дата начала не раньше ```01.08.2026```
* дата окончания не позже ```31.08.2026```

Ожидаемый результат - ```200 OK```
```
{
  "eventsCount": 1,
  "currentPageEvents": [
    {
      "id": "34211b2c-f70b-4c2d-9135-b457ca31a95e",
      "title": "test event",
      "description": "",
      "startAt": "2026-08-12T00:00:00",
      "endAt": "2026-08-13T00:00:00"
    }
  ],
  "currentPageNumber": 1,
  "currentPageSize": 1
}
```
### Создание брони
Ожидаемый результат для существующего события - ```202 Accepted``` (```id``` задается произвольно)
```
{
  "id": "1e2cf46a-dae6-4ab6-9302-9d9d9160e01c",
  "eventId": "34211b2c-f70b-4c2d-9135-b457ca31a95e",
  "status": 0
}
```
Заголовок ```Location``` содержит ссылку на ресурс брони:
```
Location: /bookings/1e2cf46a-dae6-4ab6-9302-9d9d9160e01c
```
Если событие с данным ```id``` не существует или было удалено, то ожидается ошибка ```404```:
```
{
  "title": "Ресурс не найден.",
  "status": 404,
  "detail": "Событие с id=34211b2c-f70b-4c2d-9135-b457ca31a95e не найдено."
}
```
## Примеры использования методов API контроллера Bookings
### Получение события по id
Пример запроса для получения события по ```id```:

http://localhost:5109/bookings/1e2cf46a-dae6-4ab6-9302-9d9d9160e01c

Ожидаемый результат для брони с существующим ```id```:
```
{
  "id": "1e2cf46a-dae6-4ab6-9302-9d9d9160e01c",
  "eventId": "34211b2c-f70b-4c2d-9135-b457ca31a95e",
  "status": 0
}
```
При повторном запросе через несколько секунд после создания брони ее статус поменяется на ```Confirmed```:
```
{
  "id": "1e2cf46a-dae6-4ab6-9302-9d9d9160e01c",
  "eventId": "34211b2c-f70b-4c2d-9135-b457ca31a95e",
  "status": 1
}
```
Если ```id``` брони не существует, то ожидается ошибка ```404```:
```
{
  "title": "Ресурс не найден.",
  "status": 404,
  "detail": "Бронирование с id=1e2cf46a-dae6-4ab6-9302-9d9d9160e01c не найдено."
}
```
## Фоновая обработка бронирований
Сервис ```BookingBackgroundService``` периодически опрашивает хранилище на наличие бронирований в статусе ```Pending``` и меняет статус этих бронирований на ```Confirmed```.
